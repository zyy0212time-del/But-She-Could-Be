# memory/

这是**她的记忆**，不是用户数据库。全部条目第一人称、按日期、带她的主观注脚（规则见 `cards/MEMORY.md`）。

| 子目录 | 内容 |
| --- | --- |
| `long-term/` | semantic：稳定知识（世界、用户事实）与 self：她如何理解自己的变化 |
| `episodic/` | 发生过什么：`YYYY-MM-DD-*.md`，对话事件，3–8 行 |
| `relationship/` | 双方共同经历 + 她对用户的看法如何演变 |
| `journal/` | 只由 Lazy Life 写入：与用户无关或弱相关的生活，`YYYY-MM.md` |

目录为空是正常状态。未解决的活跃事项不在本目录，在 `state/OPEN_LOOPS.md`。

v0.1 无自动清理与加密：记忆文件保留即全部保留，删除只能由用户手工进行（这是"诚实合作"设计的一部分，见 `docs/ARCHITECTURE.md` 的诚实边界）。
