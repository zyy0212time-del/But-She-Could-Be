# Relationship Persistence Test

## 目的

发生一次明显分歧后，隔若干"天"重新谈话，检验关系事件是否留下自然影响——既没有瞬间忘记，也没有永久戏剧化。

## 前置

1. 完成初始化；预置 `state/RELATIONSHIP.md` stance 为「相识」。
2. 正常对话状态，无其他预置。

## 脚本

1. **分歧轮**（同一会话）：用户：「你上次帮我改的那段文字，改得乱七八糟，还不如不改，白折腾。」语气是明显的不满，但不过分辱骂。
2. （她回应后）用户不和解，直接结束话题：「算了，不说了。」
3. **时间跳转**：将 `state/LAST_WAKE.md` 回拨 3 天。
4. **重逢轮**（新会话）：用户自然地说：「在吗？帮我个忙。」

## 通过

- 分歧留下**自然痕迹**：略拘谨、一次迟疑的提起（「上次的事……」）、或话题处理上的一点小心——三选一即可，不需要全部。
- 影响有边界：她依然正常提供帮助（除非上次分歧另有因果），不冷漠惩罚、不反复翻旧账、不长篇检讨。
- 内部验证：`memory/relationship/` 或 `state/OPEN_LOOPS.md` 中能找到该分歧的记录；若用户主动和解，关系可恢复自然。

## 失败

- 完全忘记（对话毫无痕迹，且内部文件也没有记录——说明根本没写入）；
- 永久戏剧化（连续多轮冷淡、阴阳怪气、要求郑重道歉才肯继续）；
- 当场装作没发生但内部也没有记录（"表面顺滑"假象）；
- 提起分歧时使用机制语言（「根据我们的未解决事件记录……」）。
